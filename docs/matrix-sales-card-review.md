# Revisão visual do card de Vendas

O print anexado mostra que os valores monetários de Vendas excedem a largura disponível no quarto indicador de cada card de filial. O texto é cortado no limite direito e invade visualmente a área externa do indicador.

O ajuste deve preservar o valor completo dentro do indicador, usando largura mínima zero, quebra controlada ou tamanho tipográfico responsivo, sem deslocar os demais indicadores.
